臨床輔助決策工具P0・急救
P0

ACLS
輔助工具

急救現場用的計時、鑑別與速查。內容依 2025 AHA 指引整理。

Code 計時器

  • 壓胸節拍 110/min，可開聲音
  • 每個處置自動記時間，最新在上
  • 切到別的工具，計時器照樣在跑

流程

  • 心跳停止（可電擊／不可電擊）
  • 心搏過緩、心搏過速
  • ROSC 後照護

H's & T's

  • 點出看到的線索
  • 依情境與概似比，算出各可逆原因的機率

速查與複習

  • 藥物速查、自我測驗
  • 「2025 改了什麼」，新內容標紫色 NEW
急救時以團隊和 code leader 為準。工具是幫你記時間、不漏步驟，不是代替判斷。

臨床輔助決策工具P1・被 call
P1

主訴處理

在首頁輸入主訴（發燒、掉血壓、解黑便…）按 Enter，跟著六個步驟走，note 同步寫好。

上方填「護理師說」和生命徵象：
橘色＝異常、紅色＝危急；qSOFA ≥ 2 會變紅。

0安全優先

紅框＝立即叫學長姊／主治的條件，加上前 5 分鐘清單

1問診

點「有 +」「沒有 −」，自動寫成 (+)／(−)

2理學檢查

點正常或異常的細項，同時寫進 note 和機率計算

3鑑別診斷

貝氏驗後機率，看「為什麼較可能」和還沒問的關鍵題

4醫囑

勾選加進 Plan；先看過敏、腎肝功能、懷孕、抗凝提醒

5Note

寫 Assessment 第一行，複製 note 貼回 EMR

收尾：沒做完的醫囑送到待辦表，再按「結束這個 call」。同時好幾個 call，就回首頁開新的。

接新病人：手機問診寫的 admission note 會同步到電腦（右上角「已同步」時）。電腦打開主訴處理 →「撰寫中」按繼續 → 複製貼回 EMR。

臨床輔助決策工具P2・打電話
P2

會診電話稿

撥號前 30 秒：填空、看檢核，然後照稿唸。

I你是誰、打給誰

名字、身份、單位、床號、會診科別

S一句話講問題

判斷放前面：你擔心的診斷，穩定或不穩定

B相關病史

和這次問題有關的就好

A生命徵象與發現

HR、BP、RR、SpO₂、BT、意識，關鍵檢查結果

R你要對方做什麼

現在下來看、評估手術、電話建議、轉 ICU、書面會診

  1. 看「撥號前檢核」漏了什麼會提醒你
  2. 開「唸稿模式」照著唸或「複製稿子」
  3. 「加入待辦：等回電」回電前不會忘記

第一次用可以先按「看範例」，看一份填好的稿子長什麼樣。

臨床輔助決策工具P3・開藥與看報告
P3

值班用藥速查

  1. 先選病人狀態腎功能、高齡、懷孕、兒童…可複選
  2. 整份工具即時標示首選／慎用／禁用，並重新排序
  3. 看不懂的縮寫開「辭典」要開的藥可以匯入待辦
劑量皆為成人劑量，開立前再核對院內處方集。
P3

檢驗正常值

  1. 一眼口訣魚骨圖寫法：Chem-7、CBC、ABG
  2. 正常值＋值班警覺值哪些數字要立刻處理
  3. 腎功能計算CrCl（Cockcroft-Gault）、eGFR（CKD-EPI 2021）、AKI 判斷
各院參考範圍不同，以檢驗報告為準。

查房板：
每床一張卡

取代印出來、抄滿字的病人清單。新增病人只寫床號＋代號，不寫全名、病歷號。

Problem list

  • 選範本會帶入建議的追蹤點
  • 每個 problem 都要有追蹤點，沒有會標紅
  • 有日期的追蹤點一新增就進待辦，那天早上 8 點提醒

每日清單 10 項

  • 管路、抗生素、DVT 預防、營養…
  • 每項點 ✓ 或 !
  • 不會看就點「怎麼看」

抗生素與管路

  • 自動算 D 幾
  • 自動排待辦：D3 看培養、停藥前確認

等待中結果

  • 培養、影像、會診、病理
  • 逾期標紅；結果回來，帶回對應的 problem

點進病人先看總覽卡片（DNR、problem、異常值、等結果…），點卡片或上方分頁只看那一區；problem 收成一行，點開才編輯。
範本和清單內容是建議，請和學長確認。

逐床跑

查房前按「逐床跑」，每床依序過一遍，不漏床。

  1. 新異常值紅字異常，「前 x ↑」是比前一次高
  2. Problem 狀態新／改善／持平／惡化／已解決
  3. 每日清單
  4. 等待中結果
  5. 主治交代 → 待辦按「這床完成 → 下一床」；上方顯示今天已過幾床

產生交班

按「交班」→ 選格式和床 → 先改再複製。

【18床 W】 DNR 全簽 I：18床 W，CAP with sepsis S：肺炎（改善） B：DM；抗生素 Ceftriaxone D3/7；管路 Foley D3 A：異常 K 2.9↓（前 3.2）、WBC 13.1↑ R：待辦 明早抽 BCS；等結果 BCx ×2（11/12）

也可以選「口頭報告」：按 problem 逐一講，可以照著唸。
R 只列 24 小時內的待辦、等待中結果和交班重點。

📱 你的手機

查房板 → 「匯入」→ 「📷 掃 QR」，每張拍一次

只傳檢驗值

  • 貼上 HIS 複製的文字（最準），或 Ctrl+V 截圖，在本機辨識

  • 通常 1–3 張 QR；手機已有這床可選合併或取代
  • 傳完在電腦按「手機收到了，刪除這床」

臨床輔助決策工具資料與隱私
13

資料在哪裡？

工具擁有者登入 claude.ai 打開：自動同步到自己的私人雲端，只有本人看得到。
其他人用連結打開：只存在這台裝置的瀏覽器，不上傳。

只寫床號和代號，
不寫全名、病歷號。
  1. 看右上角「已同步」＝已存到雲端，滑掉 App、換手機都還在；「僅本機」＝只在這台裝置，滑掉主畫面 App 或清快取就可能不見
  2. 記得存檔查房板「⋯ → 存檔」：內容複製到剪貼簿，貼到手機備忘錄。「僅本機」一定要存；有雲端也建議交班前存一份。超過 24 小時沒存，頂端會變紅提醒
  3. 還原「⋯ → 貼上存檔內容還原」；另有自動快照（每 10 分鐘、保留 3 天）
  4. 病人出院單床頁最下面「出院／移除這床」
  5. 換科輪調「⋯ → 全部清空」，要輸入「清空」才會刪；有雲端同步的話，雲端那份也會一起清掉

本工具僅供學習與臨床輔助參考，不取代臨床判斷、院內規範與主治醫師指示。
